# MVP for Startup

A B2B, voice first, time boxed coaching assistant that employees use in off screen moments like commuting or walking, which pulls company playbooks and policy context plus the employee’s role history and current task context to run structured practice reps for high stakes conversations like SWE interviews, consulting cases, sales calls, or support scenarios, dynamically adjusts pacing and difficulty based on time remaining and detected uncertainty or confidence in their tone, and outputs measurable scorecards and next drills that improve performance and ramp speed.

The v0 MVP will be B2C customer focused.
This will allow us to get traction in the market before we pitch to enterprises/VCs.
